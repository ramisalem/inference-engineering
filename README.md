# Inference Engineering: a 13-week course

A self-paced course from app developer to inference engineer, following
[roadmap.sh/inference-engineering](https://roadmap.sh/inference-engineering).
12 Oct 2026 → 10 Jan 2027, about 5 hours a week, $0 of hardware beyond an M1 Pro and free Colab/Kaggle GPUs.

**Read it:** https://ramisalem.github.io/inference-engineering/

| Folder | What's in it |
|---|---|
| `lessons/` | One HTML page per lesson: reading, a hands-on lab, exercises with instant feedback |
| `reference/` | Syllabus, schedule, and cheat sheets |
| `labs/` | Lab guide and the measuring tools (`labs/tools/*.py`) |
| `portfolio/` | `LOG.md`: measured results and takeaways from every lab |
| `notes/` | My notes, one file per lesson (shown at the bottom of each lesson) |
| `assets/` | Shared CSS and JS components |
